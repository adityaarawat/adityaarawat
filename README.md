# ☁️ Azure + Terraform

One of the areas I enjoy most is turning cloud infrastructure into reusable Terraform modules.

```hcl
module "network" {
  source = "./modules/network"

  environment = var.environment
  location    = var.location
}

module "compute" {
  source = "./modules/compute"

  environment = var.environment
  location    = var.location
}
```

The idea is simple:

> **Write infrastructure once. Reuse it everywhere.**
